# Random Strings

CISP 310 Project 1. An x86 MASM program (Irvine32) that prints random uppercase strings.

## Build

Open `Project1.slnx` in Visual Studio (with the MASM build customization enabled) and run. Irvine32 must be installed; update the Irvine paths in `Project1.vcxproj` if yours differ.

## Files

- `project1.asm` - source code
- `Project1.slnx`, `Project1.vcxproj`, `Project1.vcxproj.filters` - Visual Studio project
